# AngelScript dependency

This project builds the unmodified AngelScript 2.38.0 core and the official `scriptstdstring` add-on as a static library.

Upstream: https://www.angelcode.com/angelscript/

The source files under `vendor/` retain the upstream zlib-style license notice. `PureMirror.AngelScript.vcxproj` is PureMirror-specific build integration and is not an upstream project file.
